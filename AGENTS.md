# Repository Guidelines

- Keep source code, comments, documentation, test names, fixtures, examples,
  and user-facing strings in English.
- Never copy names, email addresses, event titles, locations, calendar IDs,
  account names, URLs, or other data from a real workstation into the
  repository.
- Use synthetic labels and reserved example domains such as `example.com`,
  `example.org`, and `.example` for tests and documentation.
- Keep real configuration and cache data outside the repository.
- `github.com/tonobo/calterm` is the canonical Go module path and is not test
  fixture data. Do not rename it as part of anonymizing examples.
